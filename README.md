# Forge-Workshop-IncogniBox

Community mod packs for the unofficial Arknights *Stronghold Protocol: Covenant* (卫戍协议：盟约) fan remake.

## Mods

| 目录 | Mod | 说明 |
| --- | --- | --- |
| [`ave-mujica/`](ave-mujica/) | 颂乐人偶 / Ave Mujica | 5 名成员干员、核心盟约与成员特质 |
| [`rimbilliton/`](rimbilliton/) | 雷姆必拓 / Rim Billiton | 9 名卡池干员、核心盟约（开拓心）、装备与策略 |

## 安装

把对应子目录（`ave-mujica/` 或 `rimbilliton/`）整体放入游戏的工坊目录即可。
