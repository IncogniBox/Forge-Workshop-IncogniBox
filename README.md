# Forge-Workshop-IncogniBox

Community mod packs for the unofficial Arknights *Stronghold Protocol: Covenant* (卫戍协议：盟约) fan remake.

## Mods

| 目录 | Mod | 说明 |
| --- | --- | --- |
| [`ave-mujica/`](ave-mujica/) | 颂乐人偶 / Ave Mujica | 5 名成员干员、核心盟约与成员特质（含战场上的 Fever 积攒进度图标） |
| [`rimbilliton/`](rimbilliton/) | 雷姆必拓 / Rim Billiton | 9 名卡池干员、核心盟约（开拓心）、装备与策略 |
| [`columbia/`](columbia/) | 哥伦比亚 / Columbia | 8 名盟约干员、核心盟约（源石辅助仪滚雪球）、4 件装备与策略 |

> 每个包目录里都自带一份 README（内容与引擎扩展点清单）。三个包的 `pack.json` 都声明 `gameVersion: 0.2.6`；
> `columbia` 另外依赖该版引擎的装备格等扩展点，逐条见 [`columbia/README.md`](columbia/README.md) §8。

## 安装

把对应子目录（`ave-mujica/`、`rimbilliton/` 或 `columbia/`）整体放入游戏的工坊目录即可。
